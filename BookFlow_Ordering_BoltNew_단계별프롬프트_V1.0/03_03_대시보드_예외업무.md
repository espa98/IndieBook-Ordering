참조 문서: Docs/03_UI_UX/Ordering_WebP0_Wireframe_UIUX_Guide_V1.1_비판적검토_개선본.md; Docs/03_UI_UX/Ordering_SFS_V1.1_OPDS승인정책반영_웹모바일상세기능명세서.md

## 이번 단계의 실행 지시
O-01, O-01-01, O-01-02 화면을 구현한다. 주문/발주/입고/안내/미수령/미결제/환급 필요/차단 예외를 구분하고 숫자는 서버 집계 또는 명시적 데모 값으로 표시한다. 확보 안내 후 7일 미수령 경고(서점별 설정 가능)를 표시하되 자동 취소·비용 부과 금지. 예외 해결은 구현된 API가 없으면 읽기 전용. 카드 클릭 시 관련 주문·업무 상세로 이동한다. 테스트: 데이터 0건, 여러 상태 동시 존재, 경고 기준일, 권한 없는 접근.

## 작업 방법
1. 현행 코드와 참조 문서의 화면 ID/필드/규칙/우선순위를 대조하고 구현 목록을 작성한다.
2. 기존 구현을 보존하면서 컴포넌트·라우트·폼·검증·오류 상태를 구현한다. 화면마다 로딩/빈 상태/오류/권한 없음/재시도 UI를 포함한다.
3. API가 실검증되지 않았으면 `DEMO MODE` 또는 비활성 기능으로 구분한다. 백엔드/DB를 임의 변경하지 않는다.
4. 가능한 테스트를 실행하고 실패한 항목은 수정하거나 근거와 함께 미완료로 보고한다.
5. 화면 ID별 변경 파일, 실제 API 연결 여부, 테스트 결과, 정책 게이트, 다음 단계 진행 조건을 한국어로 요약한 뒤 멈춘다.

## 완료 기준
- 문서에 정의된 P0 화면 동작과 오류 상태가 확인된다.
- 미승인 정책은 활성화되지 않는다.
- 테스트되지 않은 API를 성공 처리하지 않는다.
- 이전 화면/데이터의 회귀 오류가 없다.
