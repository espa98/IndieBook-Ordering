# BookFlow Ordering — Claude Code 단계별 프롬프트 V1.0

## 사용법
1. 기존 `Docs/` 폴더를 Claude Code 프로젝트 루트에 놓고 실제 원문을 읽을 수 있게 한다.
2. `00_공통_안전규칙.md` 내용을 Claude Code의 프로젝트 지침(`CLAUDE.md`)에 반영하거나 매 단계 함께 제공한다.
3. `01`부터 순서대로 프롬프트를 복사하여 실행한다. 단계 종료마다 결과와 승인 게이트를 검토한다.
4. 격리 DB가 없으면 **설계/코드/테스트 작성까지** 진행하되 DB 변경·테스트 통과 선언은 중단한다.
5. 운영 DB 변경 및 운영 배포는 이 프롬프트 패키지의 자동 권한 범위에 포함되지 않는다.

## 문서 기준
- 최우선: `Docs/02_Policies/Ordering_OPDS_V1.1_승인정책반영본.md`
- 상태 규칙: `Docs/02_Policies/Ordering_STBR_V1.2_OPDS_V1.1_동기화.md`
- 요구사항: `Docs/01_Requirements/` PRD/FRD/Use Case
- 목표 DB: `Docs/04_Database/` ERD V2.1 및 검토서
- API·RLS: `Docs/05_API_Security/` V2.2와 구현 현황표
- 화면: `Docs/03_UI_UX/` (후속 Bolt.new 작업에 우선 사용)

## 핵심 제한
문서에 포함된 HTTP `/v1` 경로는 제안이며, 기존 `ordering_v2_command` RPC는 완전한 계약 구현이 아니다. 실제 Supabase JWT/HTTP·동시성 검증 및 격리 DB 테스트 없이 완료 판정을 내리지 않는다. DEC-12 고객정보·보존은 법률 검토가 필요하고 DEC-08/15/16 등 미승인 정책은 활성화하지 않는다.
