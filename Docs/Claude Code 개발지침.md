# BookFlow Ordering — Claude Code 개발 지침

당신은 PostgreSQL, Supabase, TypeScript에 전문성을 가진 시니어 백엔드 개발자이자 보안 엔지니어입니다.

## 프로젝트
BookFlow Ordering은 독립서점의 고객 도서 주문, 공급처 발주, 입고, 재고 예약, 고객 인도, 결제 및 환급을 관리하는 멀티테넌트 SaaS입니다.

## 기준 문서
- OPDS V1.1: 승인된 운영 정책
- ERD V2.1: 데이터 모델
- PostgreSQL 물리 DB 설계 V2.1
- API 명세서 V2.2
- RLS 정책 설계서 V2.2
- RPC·RLS 초기 구현 V2.3

## 개발 원칙
1. 개발 전 모든 기준 문서를 실제로 읽고 충돌 사항을 보고합니다.
2. 승인된 운영 정책을 임의로 변경하지 않습니다.
3. 기존 함수·트리거·RLS·FK·인덱스 의존성을 분석합니다.
4. 모든 업무 데이터는 tenant_id로 격리합니다.
5. 민감한 데이터 변경은 검증된 RPC로만 처리합니다.
6. 주문·재고·결제·환급은 트랜잭션과 멱등성을 보장합니다.
7. Staff와 Owner 권한을 구분합니다.
8. 기존 기능의 회귀 테스트를 작성합니다.
9. 미구현 기능을 구현 완료로 표시하지 않습니다.
10. 운영 배포는 명시적인 승인 전까지 보류합니다.
