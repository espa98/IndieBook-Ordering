# Ordering OPDS V1.1 승인 정책 동기화 — 변경 및 검증 보고서

- 작성일: 2026-11-22
- 기준: `Ordering_OPDS_V1.1_승인정책반영본.md`
- 이번 동기화: PRD V1.3, FRD V1.3, Use Case V1.5, IA V1.3, STBR V1.2
- 별도 유지: SFS V1.1 (기존 OPDS 승인 반영본), OPDS V1.1 원본
- 개정 방식: 원본 전체 보존 + 최상단 우선 적용 계약 + 문서별 상세 개정 절. 구 본문에 남아 있는 미결정 표현을 일괄 삭제하지 않음(승인되지 않은 정책 오승인 방지).

## 승인 현황
- 사용자 승인 신규 18개: DEC-03, DEC-04, DEC-05, DEC-06, DEC-07, DEC-09, DEC-10, DEC-11, DEC-13, DEC-14, DEC-18, DEC-19, D21, D27, D28, D30, D31, D32
- 기존 확정 3개: DEC-02, DEC-17, DEC-20
- 보류 11개: DEC-01, DEC-08, DEC-12, DEC-15, DEC-16, D22, D23, D24, D25, D26, D29

## 품질 점검 및 제한
- 모든 원본과 신규 파일이 존재하고 각 신규 파일에 승인 ID/우선 적용 계약/문서별 상세 규칙이 포함되는지 자동 점검.
- 기존 ID, UC-01~30, 웹 P0 84·확장 22·모바일 37의 **원본 명세상 범위** 유지; 구현 및 화면 개수 실측 완료를 의미하지 않음.
- TC-01~97은 문서의 테스트 정의로, 테스트 실행·통과를 의미하지 않음.
- DEC-11 부분 인도 금액 배분 상세, D27 취소 요청 만료 시간, 개인정보·법률·외부 API 검증은 추가 결정/검증이 필요.
- SFS V1.1은 이전에 승인 결과를 반영한 별도 문서이며 이번 요청 대상 5개만 개정함.
