# Ordering 웹 P0 와이어프레임 V1.0 비판적 검토 보고서

- 검토 대상: `Ordering_WebP0_Wireframe_UIUX_Guide_V1.0.md`, `Ordering_WebP0_Interactive_Wireframe_V1.0.html`
- 비교 기준: IA V1.3, SFS V1.1, OPDS V1.1, STBR V1.2
- 결과: 기존 29개 도식 보존 및 수정, 신규 4개 장(§11~14) 추가, HTML 시연 안내 개선

## 핵심 발견

1. **중요:** HTML이 실제 화면이 아닌데도 대시보드 건수와 거래가 실데이터처럼 보일 수 있었다. 시연 배지와 가상 숫자 표시를 추가했다.
2. **중요:** HTML의 일반 입력폼과 동일한 저장 토스트는 개발 가능한 업무 프로토타입으로 오인될 수 있었다. 문서에 화면별 서버 검증 계약을 보강하고 HTML을 탐색용 목업으로 한정했다.
3. **중요:** 결제·환급 증빙, 점주 승인, 원장 기록의 구분이 충분히 시각화되지 않았다. 상태별 처리·차단 규칙을 추가했다.
4. **중요:** 주문 상세의 확보·인도 수량 중복 차감 위험을 UI 산식으로 명시했다.
5. **중요:** 29개 와이어프레임과 10개 HTML 화면이 IA 전체 84개 화면 단위를 충족하는 것처럼 읽힐 위험이 있어 적용 범위를 구분했다.
6. **보완:** 접근성, 동시성 충돌, 승인 대기, 개인정보 마스킹, 반품 실물 귀속 및 UI 인수 테스트 18개를 추가했다.

## 남은 제한

- HTML은 데이터 연결 없는 목업이며 화면별 입력 타입을 실제로 구현한 고충실도 프로토타입은 아니다.
- IA의 나머지 55개 P0 화면 단위는 별도 와이어프레임 작업이 필요하다.
- 본 문서의 UI 제안은 OPDS 승인 정책을 변경하지 않는다.
